# Tools and Libraries

## 1. LLM Access
- OpenAI: Access language models through an API.
- Transformers: Work with pretrained language models.
- PyTorch: Support model inference and computation.

## 2. Data Processing
- Pandas: Dataset loading, cleaning, and analysis.
- NumPy: Numerical operations and statistical calculations.
- Datasets: Load and manage benchmark datasets.

## 3. Evaluation
- Scikit-learn: Evaluation metrics and statistical analysis.
- Sentence Transformers: Embeddings and semantic similarity.
- tiktoken: Estimate token usage and API cost.

## 4. Visualization
- Matplotlib: Generate experimental plots.
- Seaborn: Statistical data visualization.

## 5. Environment
- Google Colab: Experiment execution.
- GitHub: Version control and research reproducibility.

## 6. Installation Status

All listed Python libraries were verified in the current
Google Colab environment. Scikit-learn version 1.6.1
was separately verified using its correct import name.
